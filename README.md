# FinestMart Grocery Store 🛒

### Grocery Store Landing Page | Figma to HTML & Sass (SCSS)

## 📌 Project Overview

FinestMart Grocery Store is a front-end web development project recreated from a Figma design as part of my Full Stack Development learning journey.

The project focuses on translating a visual design into a grocery store landing page using HTML5, CSS3, and Sass (SCSS).

The interface features a modern grocery shopping concept, a prominent hero section, product categories, custom typography, and colorful visual elements.

## 🛠️ Technologies Used

- **Figma** – Visual design reference.
- **HTML5** – Web page structure and content.
- **CSS3** – Layout, typography, and visual styling.
- **Sass (SCSS)** – Stylesheet organization and CSS preprocessing.
- **Git & GitHub** – Version control and project management.

## ✨ Features

- Grocery store landing page recreated from a Figma design.
- Hero section with promotional messaging and imagery.
- Search bar interface.
- Grocery product category cards.
- Navigation menu and call-to-action buttons.
- Styles organized using Sass (SCSS).

## 🎯 Learning Objectives

- Practice converting Figma designs into HTML and CSS.
- Strengthen page layout and visual styling skills.
- Apply Sass (SCSS) to organize stylesheets.
- Improve visual accuracy when recreating a design.
- Practice organizing front-end project files.
- Develop Git and GitHub workflow skills.
